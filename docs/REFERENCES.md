## Convenciones del paquete

Los documentos se inspiran en prácticas de arquitectura empresarial, pero están dimensionados para PersonalOS. No se pretende copiar la burocracia de una empresa grande ni afirmar que Microsoft use exactamente esta estructura de carpetas.

El objetivo es adoptar principios transferibles:

- requisitos explícitos;
- decisiones registradas;
- diagramas;
- atributos de calidad;
- seguridad;
- pruebas;
- observabilidad;
- trazabilidad;
- revisión continua.
