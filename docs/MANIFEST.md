## Instalación

Copie `AGENTS.md` a la raíz del repositorio y combine la carpeta `docs` con la carpeta `docs` existente.

No elimine:

- `docs/PersonalOS_Dossier_v1.0.md`
- `.gitattributes`
- `.editorconfig`
- `.gitignore`
- `global.json`

Este paquete complementa el dossier existente; no lo reemplaza.

La documentación es viva. Cada cambio significativo debe actualizar requisitos, decisiones, pruebas, riesgos y estado de implementación.
